# Samples

| File | What it is | Source and licence |
|---|---|---|
| `webshop.js` | A small shop with common mistakes, written for Joinscope (`src/webshop.sql`) | MIT, as Joinscope |
| `webshop-fixed.js` | Webshop with the fix script Joinscope wrote applied (`src/webshop-fixed.sql`), to try Compare | MIT, as Joinscope |
| `chinook.js` | Chinook, a digital music store | [lerocha/chinook-database](https://github.com/lerocha/chinook-database), MIT, see `LICENSE-chinook.md` |
| `pagila.js` | Pagila, the PostgreSQL version of Sakila | [devrimgunduz/pagila](https://github.com/devrimgunduz/pagila), PostgreSQL licence, see `LICENSE-pagila.txt` |
| `sakila.js` | Sakila, a DVD rental shop | [MySQL AB](https://dev.mysql.com/doc/sakila/en/), BSD, notice kept inside the file |
| `northwind.js` | Northwind, a small trading company (SQL Server) | [microsoft/sql-server-samples](https://github.com/microsoft/sql-server-samples/tree/master/samples/databases/northwind-pubs), MIT, see `LICENSE-northwind.txt` |
| `hr.js` | HR, Oracle's human resources schema (Oracle) | [oracle-samples/db-sample-schemas](https://github.com/oracle-samples/db-sample-schemas), MIT, see `LICENSE-hr.txt` |

Rebuild one with `node tools/make-sample.js` (see CONTRIBUTING.md).
